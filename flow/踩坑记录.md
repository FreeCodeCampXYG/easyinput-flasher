## 2026-08-30 · 初始 Vite 版本存在开发服务器安全告警   [已解决]
- **现象**: `npm audit` 报告 Vite 6.0.7 与其 esbuild 链存在 Windows 路径读取相关告警。
- **根因**: 初始前端模板锁定版本落在已披露问题范围内。
- **解决**: 最小升级到兼容的 `vite 6.4.3`，重建 lockfile 后 `npm audit` 为 0 漏洞，类型检查和生产构建通过。
- **教训 / 怎么避免**: 新增桌面前端依赖必须先锁定版本并运行 audit；不执行无审查的 `npm audit fix --force`。
