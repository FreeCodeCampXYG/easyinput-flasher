# EasyInput Flasher v0.1.0

EasyInput Flasher 是面向 EasyInput V2.0 / ESP32-S3 的独立桌面烧录器。它不在本机编译固件，而是从受信任的 GitHub Release 下载版本化固件清单和三段镜像，完成 SHA-256 校验、下载模式验身和人工确认后才调用烧录辅助程序。

## 本版能力

- 深色侧栏工作台：烧录、固件库、发现、设备与日志、更新、帮助和底部状态栏。
- GitHub Release 来源、代理模式、下载缓存和 manifest 白名单。
- `easyinput-v2` + `esp32s3` 固定目标检查，三段镜像 SHA-256 校验。
- 串口候选扫描、ESP32-S3 下载模式只读验身、MAC 尾号确认和可取消写入状态机。
- 写入后正常 HID 恢复检查；写入成功、HID 恢复和具体功能验证分开报告。
- Maker 固件的 `firmware-v*` 工作流合同：发布 manifest、哈希和构建溯源供本应用使用。

## 平台资产与验证边界

| 平台 | 资产 | 当前证据 |
| --- | --- | --- |
| Windows x64 | 便携 ZIP | 本机 Wails 构建通过；真实烧录待验证 |
| Windows ARM64 | 便携 ZIP | GitHub Actions 原生构建待验证 |
| macOS Intel / Apple Silicon | `.app` ZIP | GitHub Actions 原生构建待验证；未签名、未公证 |
| Linux x64 / ARM64 | TAR.GZ | GitHub Actions 原生构建待验证 |

请只下载匹配系统架构的资产，并校验同名 `.sha256` 文件。CI 构建成功不等于任何平台的设备烧录已验证，欢迎提交 Issue 补充串口、权限、下载模式和恢复结果。

## 烧录步骤

1. 使用支持数据传输的 USB 线连接 EasyInput V2.0。
2. 在应用中选择具有 `firmware-manifest.json` 的受信 Release。
3. 扫描端口并读取设备信息。正常 HID 模式没有 CDC 串口是预期行为。
4. 自动连接失败时，保持开发板开机，短按并松开一次 BOOT；重新扫描并验身。
5. 核对 ESP32-S3 与 MAC 尾号，输入应用显示的确认文本。
6. 写入期间不要拔出 USB、关闭电源、再次按 BOOT 或退出应用。
7. 若本轮手动进入下载模式，烧录后通过电源开关完全关机再正常开机；随后执行 HID 恢复检查。

不要按住 BOOT 再上电，不要将 GPIO0 当业务按键，也不要把整片擦除当作常规操作。

## 已知限制

- 当前历史固件 Release 没有 manifest 时会被安全忽略。
- 本版不提供 OTA、自动擦除、未受信来源自动烧录或自动更新安装。
- macOS 未使用 Developer ID 签名和 notarization；用户需要自行完成系统安全与 USB/串口权限授权。
