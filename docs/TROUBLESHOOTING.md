# 故障排查

| 现象 | 处理 |
| --- | --- |
| 已发现正常 HID、没有下载串口 | 这是正常阶段；保持开机，短按并松开一次 BOOT，再点击“刷新下载端口”。 |
| 刷新后仍未发现下载端口 | 检查数据线、供电和系统端口列表；不要退回“按住 BOOT 上电”流程。 |
| 芯片不匹配 | 立即停止，选择正确 ESP32-S3 设备。 |
| 固件校验失败 | 删除缓存后重试；不要绕过 manifest 或哈希。 |
| 写入后仍在下载模式 | 不再次按 BOOT；关机后重新开机。 |
| HID 未恢复 | 确认电源已完全关闭再启动；记录脱敏错误摘要，不要上传完整设备信息。 |

`flash` 成功只表示写入工具完成。应用启动、HID 枚举和具体按键/BLE/音频功能需要分别验证。
